## Siapa Kami?

**Neosantara (NAI)** adalah platform AI independen yang dikembangkan untuk menyediakan teknologi AI tingkat lanjut bagi pengembang dan organisasi.

## Apa itu Neosantara API?

Membangun aplikasi AI yang memanfaatkan data daring waktu nyata atau kemampuan multimodal tingkat lanjut bisa menjadi rumit. Neosantara hadir sebagai platform gateway terpadu yang menyediakan akses API standar ke berbagai model bahasa besar (LLM) dan model AI multimodal dari berbagai penyedia.

Alih-alih mengelola banyak integrasi API, sistem autentikasi, dan platform penagihan dari penyedia AI berbeda, Neosantara menggabungkan semuanya ke dalam satu API yang konsisten. Kamu dapat fokus membangun aplikasi inti sementara kami menangani kompleksitas integrasi, optimasi, dan keandalan model.

<Note>
   **Neosantara adalah produk independen dan tidak berafiliasi dengan, didukung oleh, atau secara resmi terhubung dengan penyedia model tersebut**. Kami berfungsi sebagai gateway API untuk membantu Kamu berinteraksi dengan teknologi mereka melalui antarmuka yang terpadu.
</Note>

<Info>
  Jika Kamu adalah pengembang AI yang ingin mengintegrasikan aplikasi Kamu dengan API kami, atau mencari peningkatan batas API, [silakan hubungi kami!](mailto:support@neosantara.xyz)
</Info>
